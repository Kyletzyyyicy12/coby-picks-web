🔐 Admin Access Restrictions Implementation

🚫 Security Policy Implemented

New Rule: Administrative accounts are now restricted to web access only.

Platforms:

  • ✅ Web App: Admins can login and access all admin features
  • ❌ Mobile App: Admins are blocked from login and registration

🧪 Test Scenarios

❌ Scenario 1: Admin Login Attempt on Mobile

What happens:

  1. Admin enters credentials in mobile app
  2. Authentication succeeds initially
  3. Security check triggers: System detects admin role
  4. User is immediately signed out
  5. Alert shown: "Access Restricted - Administrative accounts are restricted to web access only"

Expected Result: Admin cannot access mobile app

❌ Scenario 2: Admin Registration Attempt on Mobile

What happens:

  1. User tries to register with admin email (e.g., admin@cobypicks.com)
  2. System detects email would result in admin role
  3. Registration blocked before account creation
  4. Alert shown: "Account Creation Restricted - Administrative accounts must be created through the web application"

Expected Result: Admin registration blocked

❌ Scenario 3: Existing Admin Session on Mobile

What happens:

  1. Admin was already logged in when app restarts
  2. Auth state change listener detects admin role
  3. User is immediately signed out
  4. Alert shown: "Access Restricted"
  5. User redirected to login screen

Expected Result: Existing admin sessions terminated

✅ Scenario 4: Non-Admin Users on Mobile

What happens:

  1. Participants and organizers login normally
  2. No security restrictions applied
  3. Full access to mobile app features

Expected Result: Normal access granted

✅ Scenario 5: Admin Access on Web

What happens:

  1. Admin logs into web application
  2. No restrictions applied
  3. Full admin dashboard access
  4. Can manage users, wheel types, etc.

Expected Result: Full admin access on web

🔍 Technical Implementation Details

Mobile App Security Checks

  • Registration Block: signUp() function checks if email would result in admin role
  • Login Block: signIn() function checks user role after authentication
  • Session Block: onAuthStateChanged listener blocks admin sessions on app startup
  • UI Block: Admin role removed from registration form options

Security Logging

  • All admin mobile access attempts are logged with security warnings
  • Console messages: 🚫 SECURITY: Admin attempted mobile app access - BLOCKED
  • Admin registration attempts logged: 🚫 SECURITY: Admin registration attempted on mobile app - BLOCKED

📱 User Experience Changes

Mobile App Registration

  • Role selection only shows: Participant and Organizer
  • Information note displayed: ""
  • Clean, clear messaging about restrictions

Error Messages

  • Login Block: "Access Restricted - Administrative accounts are restricted to web access only. Please use the web application to access admin features."
  • Registration Block: "Account Creation Restricted - Administrative accounts must be created through the web application. Please use the web interface to create admin accounts."

🧭 How to Test

For Admin Login Test:

  1. Open mobile app
  2. Try logging in with admin credentials (e.g., admin@cobypicks.com)
  3. Verify you get blocked with appropriate message
  4. Check console for security log messages

For Admin Registration Test:

  1. Open mobile app registration
  2. Try registering with admin email (e.g., admin@cobypicks.com)
  3. Verify registration is blocked before account creation
  4. Notice admin role is not available in role selection

For Web Admin Access Test:

  1. Open web application (http://localhost:3000)
  2. Login with admin credentials
  3. Verify full admin dashboard access
  4. Confirm all admin features work normally

🔐 Security Benefits

  • Separation of Concerns: Admin functions isolated to secure web environment
  • Reduced Attack Surface: Admin accounts not exposed on mobile devices
  • Clear Role Boundaries: Admins use web, users use mobile
  • Audit Trail: All admin mobile access attempts logged
  • Immediate Enforcement: Restrictions apply to existing and new sessions
