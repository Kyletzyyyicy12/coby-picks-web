# CobyPicks Promotional Site

A beautiful, modern promotional website showcasing the comprehensive features and capabilities of the CobyPicks Interactive Wheel System.

## 🎯 Overview

This promotional site highlights the entire CobyPicks ecosystem, including:
- **Web Application** (Next.js + React + TypeScript)
- **Mobile Application** (React Native + Expo)
- **Real-time Collaboration Features**
- **Advanced Auto-Spin Technology**
- **Cross-Platform Synchronization**
- **Enterprise Security & Admin Controls**

## 🚀 Usage Instructions

### Viewing the Site
1. Open `index.html` in any modern web browser
2. Navigate through the sections using the navigation menu
3. Click "Features" to view the detailed features page
4. Interactive elements respond to hover and click events

### Customization
- **Colors**: Modify CSS variables in `styles.css`
- **Content**: Update HTML content in `index.html` and `features.html`
- **Animations**: Customize JavaScript animations in `script.js`
- **Branding**: Replace logo and brand colors throughout the files
